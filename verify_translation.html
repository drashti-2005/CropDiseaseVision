💡 Troubleshooting Tips

  • ❌ API Not Working? → Check internet connection, LibreTranslate might be down
  • ❌ Backend Not Found? → Make sure Flask server is running: python backend/app.py
  • ❌ Language Not Saving? → Check if localStorage is enabled in browser settings
  • ❌ Translation Slow? → First call uses API (1-2s), repeat calls use cache (<10ms)
